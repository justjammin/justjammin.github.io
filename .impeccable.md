# netrunner

## Design Context

### Users
Recruiters, engineering managers, and collaborators landing on Jamin's personal portfolio, usually
from a link in a GitHub profile, a resume, or a DM. They arrive on a phone as often as a laptop,
they are skimming, and they have roughly fifteen seconds of patience before they decide whether
this person is interesting. A secondary audience is other engineers and the gaming/music circles
Jamin is part of, who will read further and click into the project links.

The job to be done: understand that Jamin is an AI engineer who builds agent tooling, confirm the
work is real and shipped, and find the one link worth clicking. promper leads because it is the
clearest expression of how he thinks about agents.

Positioning note: the cloud and CI/CD skills are real and stay on the page, but they are support,
not the headline. Jamin is not a DevOps engineer.

### Brand Personality
Clinical, aggressive, machine-precise. The voice of a system readout rather than a person talking
about themselves. Short declaratives, technical nouns, nothing that reads like a pitch. Warmth arrives only in the
personal facts (music, gaming, family projects), and it lands harder because everything around it is
cold. Emotional goal: the visitor should feel like they breached a terminal and are reading someone
else's dossier.

### Aesthetic Direction
Cyberpunk 2077 netrunner quickhack panel, executed as the game actually renders it rather than as
the generic "neon cyberpunk" cliché.

- **Theme: dark.** Derived from context, not defaulted to. The reference material is an in-game
  combat HUD read in a dark environment, and the source site already establishes a game-menu shell
  with full-bleed video. Light mode would fight the entire premise.
- **Amber is primary.** Cyberpunk's real UI signature is a hot yellow (`#fcee0a`), not cyan. Cyan is
  demoted to a secondary scan/data accent and red is reserved strictly for alert states. This is the
  single decision that separates the page from AI-default "cyan on black."
- **Angular, never rounded.** Every frame corner is a `clip-path` notch. No border radius anywhere.
- **Anti-references:** rounded cards with drop shadows, purple-to-blue gradients, gradient text,
  glassmorphism used decoratively, Orbitron/Rajdhani "sci-fi font" shorthand.

### Design Principles
1. **The interface is a readout, not a brochure.** Every label is a system field: `RAM`, `RANK`,
   `STATUS`, `TRACE`. Content inherits the source site's existing game-menu IA (LOG panels, ranks
   I–IV, ↑↓ NAVIGATE) instead of inventing a new one.
2. **Amber leads, cyan supports, red warns.** Accents work because they are rare, roughly 60%
   near-black surface, 30% muted structure, 10% live accent.
3. **Depth through parallax layers, never through scroll-jacking.** Transform and opacity only,
   scrubbed to native scroll. The user's scroll always does what they expect.
4. **Motion is a system booting, not decoration.** Reveals read as decryption and upload, and every
   one of them is gated behind `prefers-reduced-motion`.
5. **Degrade honestly.** No blank rectangles waiting on an asset. Video carries a poster, the WebGL
   layer never mounts if it is unwanted or unsupported, and the page is fully readable with
   JavaScript disabled.
